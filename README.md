# Course Curriculum Builder

Live Demo: https://bakti27.netlify.app/

---

## Overview

This tool simplifies the creation of professional training and course documentation. It converts raw content into a structured, print-ready brochure with sections such as overview, objectives, modules, and conclusion.

---

## Features

- Upload and parse `.docx` files using Mammoth.js  
- Automatic extraction of structured course content  
- Real-time preview of curriculum layout  
- A4 page formatting optimized for printing  
- Dynamic generation of module pages  
- Smart content distribution across pages  
- Export to PDF using browser print  
- Multiple font selection options  
- Sample data generation for testing  

---

## Tech Stack

- HTML5  
- CSS3 (including print styling)  
- JavaScript (Vanilla)  
- Mammoth.js (Word document parsing)  
- Netlify (deployment)

## How It Works

1. Enter course details manually or upload a `.docx` file  
2. The application parses and organizes the content  
3. A formatted brochure is generated in real time  
4. Export the final output as a PDF
